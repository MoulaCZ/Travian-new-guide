# First Village

## Hero

- Put all hero points into **combat strength**
- Switch to **resource production** (keep 4 points on strength) only when resource production from points exceeds what you earn from farming oases — calculate by comparing oasis raid income vs. production gain over the same timeframe
- Use the **Book of Wisdom** (found on adventure #6) to respec — don't use it before that
- **Never let your hero die** — if health is low, hold quests and collect them right as the hero is about to level up so they heal on level-up
- Always use the battle simulator before sending hero to an oasis — click **Apply Losses** to check health cost

## Parties (Culture Points)

The **first party must be queued within 24 hours of server start**.

If you reach step 54 well before 24 hours, don't queue the party yet — use the extra time to build more culture point sources first, then queue so that you'll have enough resources by the 24h mark.

**Priority before queuing the first party:**

1. **6 Crannies → level 7** (+12 CP each, 1,635 resources per cranny)
2. **Marketplace → level 12** (+16 CP, 16,655 resources total)
